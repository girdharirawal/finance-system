Welcome to the Financial System Project. This system provides a robust platform for financial operations, including secure payment processing, account management, and financial data analysis. The project is built using a React frontend, a set of Node.js microservices for backend processing, and is deployed using Kubernetes on Google Cloud Platform (GCP).

🚀 Project Structure
finance-system/
├── frontend/                    # React application
├── backend/                     # Node.js microservices
├── IaaC/                        # Infrastructure as Code using Terraform
│   └── finance-system-gcp-infra/
├── .deployment/k8s-manifest/   # Kubernetes manifests
│   └── overlays/
└── README.md
